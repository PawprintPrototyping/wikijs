# Dishwasher

We have a small countertop dishwasher for cleaning reusable kitchenware.  Having a dishwasher means we can reduce our reliance on disposable solo cups. 

It is a Comfee model CDC22P1ABB.

Please only use the dishwasher for cleaning kitchen items.

I recommend running glasses using the Normal, BabyCare, or Eco setting for lightly soiled glassware.
